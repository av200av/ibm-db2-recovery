# ibm-db2-recovery
Read‑only IBM Db2 recovery tool. Recover corrupted Db2 database containers and damaged backup images, supports Db2 9.7 ~ Db2 12.1 for LUW.
## IBM Db2 Recovery Tool v1.0.0

First public release of read‑only IBM Db2 forensic recovery utility for Db2 for LUW.

### Supported Versions
‑ IBM Db2 9.7 ~ Db2 12.1 (Linux / UNIX / Windows)

### Features
‑ Recover data from corrupted Db2 tablespace container files
‑ Extract records from damaged Db2 disk backup images
‑ Handle databases that cannot be activated normally
‑ Read‑only scanning with data preview before export

### Downloads
‑ `IBMDb2Recovery‑v1.0.0‑win‑x64.zip` — Windows x64 pre‑built binary

### Note
Binary protected with VMProtect. Antivirus false‑positive may occur.
The program operates fully read‑only and never modifies input container or backup files.
